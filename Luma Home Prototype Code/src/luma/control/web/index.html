Connect your services

Provider credentials are configured in this device’s local .env file. Search uses Brave; SMS uses Twilio; appointments use Cal.com; lights use your Home Assistant server. Configure approved merchant links for shopping. Enabling a switch does not create an account or subscription.

Payments stay at the merchant, where you can use a saved wallet. Luma does not store card numbers, place an order, or claim it found the lowest total price. Verify availability, tax and delivery at checkout.
